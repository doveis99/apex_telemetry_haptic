# ATS ハプティクス for Flydigi APEX 6 Pro

[한국어](README.md) · [English](README.en.md) · **日本語** · [简体中文](README.zh.md)

American Truck Simulator / Euro Truck Simulator 2 のテレメトリーで、Flydigi APEX 6 Pro の VCM（ボイスコイル）モーターを直接駆動します。ゲームの音を解析する X-Haptics と違い、エンジン回転数、路面、サスペンション、ペダルといったゲームデータから振動を作り、ウィンドウでリアルタイムに調整できます。

![メインウィンドウ](docs/screenshot-main.png)

> スクリーンショットは韓国語の画面です。画面の言語は Windows の表示言語に従い、右上の言語メニューで切り替えられます。

## 動作環境

- Windows 10/11
- Flydigi **APEX 6 Pro**（有線または 2.4 GHz ドングル。Bluetooth と無印の APEX 6 には対応していません）
- American Truck Simulator または Euro Truck Simulator 2
- 実行中は **xHaptics Engine を終了してください。** 同じモーターに出力するため振動が混ざります。Space Station の Web ページはタブを閉じておけば十分です。

## インストールとクイックスタート

1. [Releases](../../releases) から `ATSHaptics-<バージョン>.zip` をダウンロードし、好きな場所に展開します。
2. `ATSHaptics\ATSHaptics.exe` を実行します。インストール作業はありません。
3. ゲームで使えるテレメトリープラグインがない場合は、[プラグイン ウィンドウ](#テレメトリープラグイン-ウィンドウ)が自動で開きます。**インストール**を押してください。
4. まず **テスト走行** → **開始** で振動が来るか確認します（ゲーム不要の 60 秒シナリオ）。
5. **ATS/ETS2 ゲーム** → **開始** を押してゲームを起動します。ゲームが始まるとコントローラーを掴み、ゲームが終わると解放します。

ゲームを起動するたびに自動で開くようにするには、[Steam 起動オプション](#ゲームと一緒に起動-steam-起動オプション)を設定してください。

## 画面の説明

スライダー、スイッチ、ボタン、表示値にマウスを少し置くと、何をするものかを説明するツールチップが出ます。下の表の内容を短くまとめたものです。

### 上部バーと出力制御

| 項目 | 説明 |
|---|---|
| **入力: ATS/ETS2 ゲーム** | ゲームのテレメトリーから振動を作ります。ATS（`amtrucks.exe`）か ETS2（`eurotrucks2.exe`）が実行中のときだけコントローラーを使います。 |
| **入力: テスト走行** | ゲームなしで決まった 60 秒の配送コースを再生し、繰り返します。エンジン始動 → トレーラー連結 → 発進時のホイールスピン → 加速とシフト（スプリッター、レンジ）→ 高速道路（左ウインカー、左のポットホール、右のランブルストリップ）→ コンクリートの継ぎ目 → 砂利道（右ウインカー）→ 木の橋 → 雪道 → 氷上のホイールスピン → 下り坂のリターダーとエンジンブレーキ → 急ブレーキ（ホイールロック、ブレーキ鳴き）→ 料金所 → ハザードを点けてバックし、ドックに「ドン」（衝突）→ パーキングブレーキ → トレーラー切り離し → 配送完了 → エンジン停止の順です。トレーラーの車輪はトラックが越えた段差を 0.45 秒遅れて踏みます。エフェクトの確認や調整に使います。 |
| **▶ 開始 / ■ 停止** | 1 つのボタンです。緑の **開始** を押すと振動を出力し、ボタンが赤の **停止** に変わります。停止するとモーターを止めてコントローラーを解放します。実行中は入力（ゲーム/テスト走行）を切り替えられません。 |
| **ゲーム検出で自動開始**（スイッチ） | オンにすると、ウィンドウが停止中ならゲームが起動した瞬間に自動で開始します。ゲーム中に自分で停止した場合は、そのゲームが終わるまで再開しません。スイッチは切り替えるとすぐ保存されます。 |
| **GitHub ↗** | このプログラムの GitHub リポジトリ（ソース、リリース、問い合わせ）をブラウザーで開きます。 |
| **言語メニュー**（例: `日本語 ▾`） | 画面の言語を選びます: 한국어、English、日本語、简体中文、Deutsch、Français、Español、Português (Brasil)、Polski、Русский。すぐに描き直され、調整値と実行状態はそのまま残り、選んだ言語はすぐ保存されます。選ぶまでは Windows の表示言語に従い、一覧にない言語なら英語になります。状態メッセージとイベントログも同じ言語で表示されます。すでに記録されたイベントの行はそのままです。 |
| **テレメトリープラグイン** | [プラグイン ウィンドウ](#テレメトリープラグイン-ウィンドウ)を開きます。 |
| **アップデート x.y.z** | GitHub に新しいリリースがあるときだけ表示されます。[アップデート](#アップデート)を参照してください。 |

### 出力の強さと出力メーター

コントローラーに送る**最終的な強さ**です。下のエフェクトごとの強さをすべて混ぜた後にかかります。範囲は 0〜150%、既定値は 100% です。

| 項目 | 説明 |
|---|---|
| **全体** | グリップとトリガーの両方にかかります。 |
| **グリップ** | 左右のグリップモーターだけにかかります。 |
| **トリガー** | トリガーモーターだけにかかります。0% にするとトリガーの振動は完全にオフになります。 |

出力を上げると、複数のエフェクトが重なったときに滑らかに飽和するよう制限（ソフトリミッター）がかかります。100% を超えると弱いエフェクトは強くなり、すでに強いエフェクトはほぼそのままです。

**メーター**は左グリップ / 右グリップ / トリガーに実際に出ている強さを示します。振動が弱い、またはないときに、どの段階で小さくなっているかを確かめるためのものです。

### 走行エフェクト

左のスイッチでエフェクトごとにオン/オフできます。オフにした行はグレーになりますが、スライダーの値と振動の場所は残るので、オンに戻せば元どおりです。

右の **振動の場所** で **グリップ**（青）| **トリガー**（オレンジ）| **両方**（紫）のどれかを押し、エフェクトごとに振動の出し先を選びます（走行エフェクトとイベントエフェクトの両方）。スライダーの色も選んだ場所の色になるので、どのエフェクトがどこへ行くか一目でわかります。オフのエフェクトで場所を押すと、その場所でオンに戻ります。表の「既定の出力」は初期設定です。左右のあるエフェクト（路面、段差、ウインカー）をトリガーに送ると、左右を合わせてトリガーに出します。トリガーのエフェクトをグリップに送ると、両方のグリップに同じように出します。すぐに反映され、**保存**すれば保持されます。

| エフェクト | 既定値（範囲） | 既定の出力 | 内容 |
|---|---|---|---|
| **エンジン** | 50%（0〜200） | 両グリップ | エンジンの点火周波数（rpm ÷ 60 × 気筒数 ÷ 2、6 気筒なら rpm ÷ 20）に 2 倍音を加えた振動です。アクセルを踏むほど、回転数が高いほど強くなります。爆発ごとに強さが少しずつ違い（±8%）、アイドリングでは気筒ごとの爆発が不ぞろいでうねり、回転数と負荷が上がるとそろいます。負荷が大きいと 3 倍音が加わって荒くなります。エンジンが止まっているときは出ません。 |
| **路面** | 60%（0〜200） | 左右のグリップ別々 | 車輪の下の路面素材と速度で強さと質感が決まり、サスペンションの細かい揺れも加わります。強さは 氷 < アスファルト < コンクリート < 雪 < 木 < 金属 < 草 < 土 < 砂利 の順です。実際のタイヤ音の低音成分を参考に、素材ごとに震えの高さが違い（氷 140 Hz、草・金属 130 Hz、アスファルト 100 Hz、砂利 85 Hz、雪 70 Hz、木 65 Hz）、遅いほど低くなります（停止時 60%）。砂利・土・雪・荒れた舗装には小石がはじける「パチパチ」が混ざり、ほとんどは小さく、ときどき大きな石が強く当たります（砂利は 1 m に約 3 個）。録音された路面音のように 1 秒に数回うねり（約 4 Hz）、サスペンションが激しく動く荒れた道ではキャブがガタつく 55 Hz の衝撃が毎秒最大 40 回混ざります。舗装の状態（滑らかな舗装 `road_smooth` < 普通の道路 < 荒れた舗装 `road_coarse` < 土をかぶった道路 `road_dirt`）も区別します。 |
| **段差** | 100%（0〜200） | その車輪側のグリップ | サスペンションが急に動くと（ポットホール、縁石、継ぎ目）衝撃を出します。実際の段差の音を参考に、大きさに応じて小さな継ぎ目は短く高い「トン」（65 Hz、0.025 秒）、大きなポットホールは低く重い「ドン」（40 Hz、0.06 秒）になり、大きな衝撃のあとはキャブが 0.3 秒ほど小さくガタつきます。左の車輪は左グリップ、右の車輪は右グリップへ行きます。トレーラーの車輪の段差は半分の強さで少し高く（+10 Hz）続きます。 |
| **ランブルストリップ** | 80%（0〜200） | その車輪側のグリップ | センターラインや路肩のランブルストリップを踏むと「ドゥルルル」と振動します。ゲームが車輪ごとに伝える路面素材（`rumble_stripe`）で検出するので、サスペンションがほとんど動かなくても鳴ります。溝の間隔（約 30 cm）と速度で周波数が決まり、時速 90 km で約 83 Hz です。トレーラーの車輪だけが乗っても半分の強さで鳴ります。 |
| **ホイールスピン** | 70%（0〜200） | 両グリップ | アクセルを踏んでいて駆動輪がトラックより明らかに速く回ると（氷、雪、泥、急発進）ザラザラと削れるような 45 Hz の振動を出します。タイヤが食いついては滑るように 13 Hz で震えます。ブレーキで車輪が止まるホイールロックは **アクセル/ブレーキ** が担当します。 |
| **シフト** | 80%（0〜200） | 両グリップ | ギアが変わるときの「ガチャッ」。クラッチを踏んだように走行振動が 0.02 秒途切れ、62 Hz でしっかり噛み合い、38 Hz の余韻が残ります。オートマチックでも動作します。 |
| **リターダー** | 50%（0〜200） | 両グリップ | リターダーの段数に比例するうなりです。速いほど音が高くなり（停止時 40 Hz → 時速 90 km 以上で 65 Hz）、低速では弱まります。エンジンブレーキはエンジンの点火リズム（6 気筒なら rpm ÷ 20）で「ダダダッ」とノックする振動で、rpm が高いほど強く、アクセルを踏むと止まります。 |
| **衝突** | 100%（0〜200） | 両グリップ | 加速度が瞬間的に大きく跳ねると（衝突、大きな衝撃）強い 50 Hz のパルスを出します。基準は[検出しきい値](#検出しきい値)で決めます。 |
| **アクセル/ブレーキ** | 40%（0〜100） | トリガー | いま踏んでいるペダルに合わせます。アクセルなら踏み込むほど強くなる 100 Hz、ブレーキなら車輪がロックしたときに 12 Hz で途切れる 110 Hz のパルスで、ロックしていなければ速度と制動量に比例する弱い振動です。 |
| **└ エンジンの脈動** | 0%（0〜100） | アクセル/ブレーキに従う | アクセルのトリガー振動をエンジンの点火リズムに合わせて揺らす度合いです。0% なら一定に鳴り、トリガーにエンジンの感触はまったくありません。上げるほどリズムがはっきりします（以前のバージョンは 80% 固定）。脈動はグリップのエンジン振動と同じ爆発に合わせるので、アイドリングで気筒ごとにそろわないうねりや、爆発ごとに少しずつ違う強さもトリガーに伝わります。ブレーキ側には影響しません。 |
| **定速時に弱める** | 60%（0〜100） | - | 長距離の定速走行で手が疲れにくいよう、回転数・アクセル負荷・ペダルが一定のままだと **エンジン** と **アクセル/ブレーキ** の振動を数秒かけてこの割合まで徐々に弱めます（約 5 秒で半分、10 秒でほぼ全部）。加速、シフト、アクセルを離す・踏み直す瞬間にはすぐ元の強さに戻ります。60% なら定速時に約 −7 dB、80% なら約 −12 dB です。0% なら弱めません。ホイールロックのパルスは警告なので弱めません。 |

### イベントエフェクト

| エフェクト | 既定値 | 既定の出力 | 内容 |
|---|---|---|---|
| **ペダル** | 60% | トリガー | アクセルかブレーキを奥まで（97% 以上）踏んだ瞬間に短く「トン」 |
| **ブレーキ鳴き** | 40% | トリガー | 約 14 km/h 以下でブレーキを踏みながらゆっくり止まるときに「キーッ、キッ」と鳴く 230 Hz。実際の録音のように 0.15〜0.5 秒ずつ途切れて鳴り、鳴るたびに音の高さが少しずつ違います |
| **トレーラー連結** | 90% | 両グリップ | 連結時に重い「ドン」、切り離し時は「ドン」に続いてエアが抜ける感触 |
| **パーキングブレーキ** | 70% | 両グリップ | かけると「ガチャン」に続いてスプリングブレーキのエアが抜ける「シューッ」（0.15 秒で大きくなり、1 秒近くかけて消える）、外すと低い「コトン」に続いて 0.3 秒後に短い「プシュッ」 |
| **エアブレーキ** | 50% | 両グリップ | ブレーキペダルを 0.3 秒以上踏んでから離すと、ブレーキチャンバーのエアが抜けて 50 Hz の「トン」に続いて短い「プシュー」（0.04 秒で大きくなり、約 0.35 秒かけて消える）。強く踏んだほど大きくなります。離すたびに出るので走行振動を弱めません |
| **ウインカー** | 50% | 点いている側のグリップ | 点滅するたびに「カチ」 |
| **エンジン始動/停止** | 80% | 両グリップ | 始動時はクランキングに続いて「ブォン」、停止時は止まりながら震えます |
| **レンジ/スプリッター** | 50% | 両グリップ | H シフターのレンジセレクターやスプリッタースイッチを操作したときに「カチッ」。オートマチック/シーケンシャルでは鳴りません。 |
| **ゲーム通知** | 50% | 両グリップ | 料金所、罰金、給油、配送完了、フェリー、列車のイベントで「トントン」と 2 回 |
| **└ イベント優先** | 70%（0〜100） | - | イベントエフェクト（シフト、衝突を含む）が鳴る瞬間、同じ場所の走行振動（エンジン、路面、ランブルストリップ、ホイールスピン、リターダー、アクセル/ブレーキ）を一瞬弱めて、イベントが埋もれないようにする度合いです。70% ならイベントがいちばん強いときに走行振動が 30% まで下がり、約 0.1 秒で戻ります。0% なら弱めません。段差は路面から出続けるエフェクトなので、走行振動を弱めません。 |

イベントエフェクトの範囲はすべて 0〜200% です。

### 検出しきい値

| 項目 | 既定値（範囲） | 説明 |
|---|---|---|
| **段差しきい値** | 20 cm/s（5〜100） | サスペンションがこの速度より急に速く動くと段差パルスを出します。下げると小さな段差にも、上げると大きな衝撃だけに反応します。 |
| **衝突しきい値** | 12 m/s²（4〜40） | ゲーム画面の 1 フレームの間の加速度変化がこの値を超えると衝突パルスを出します。普段の走行中に[テレメトリー](#テレメトリー)の「最大加速度」に出る値より十分高くしてください。 |
| **気筒数** | 6（4〜12） | エンジン振動の周波数計算に使います。ATS の純正トラックはほとんどが直列 6 気筒で、ETS2 の Scania V8 のようなトラックは 8 にします。テレメトリーには気筒数の情報がないため手動で指定します。 |

### テレメトリー

ゲームからいま受け取っている値です。振動がおかしいときに、データが正しく届いているかを確かめるためのものです。

| 項目 | 説明 |
|---|---|
| **速度 / RPM / ギア** | ゲームの値そのままです。後退ギアはマイナス、ニュートラルは 0 です。 |
| **ペダル** | アクセル/ブレーキの入力（0〜1）です。クルーズコントロールのようにゲームが代わりに踏む値は含みません。 |
| **路面** | 最初の車輪の下にある路面素材のゲーム内部名です（例: `road`、`gravel`、`grass`）。 |
| **トリガー** | トリガーチャンネルがいま追っているペダルです（アクセル/ブレーキ/-）。 |
| **最大加速度** | 直近 0.1 秒間の水平加速度の最大値です。衝突しきい値を決めるときの参考にします。 |

### イベントログ

シフト、衝突、ペダル踏み切り、トレーラー、パーキングブレーキ、ウインカー、エンジン始動/停止、ゲーム通知が時刻とともに記録されます。コントローラーの接続トラブルもここに残ります。直近 50 件まで表示されます。

### 保存、既定値、デバッグ記録、遅延表示

| 項目 | 説明 |
|---|---|
| **保存** | スライダー、オン/オフの状態、振動の場所（グリップ/トリガー/両方）を `%APPDATA%\ATSHaptics\config.json` に保存します。未保存の変更があると **保存** ボタンが青くなり「変更あり · 未保存」と表示され、ウィンドウを閉じるときに保存するか尋ねます。 |
| **既定値** | すべての強さ、しきい値、振動の場所を既定値に戻し、すべてのエフェクトをオンにします。保存は別に押す必要があります。 |
| **デバッグ記録**（スイッチ） | オンにすると、コントローラーを掴むたびに（開始、ゲーム起動、接続が切れてつながり直したとき）コントローラーへ送った 8 ms ブロックを 1 行ずつ `%APPDATA%\ATSHaptics\logs\blocks-<日付>-<時刻>.csv` に記録します。列は時刻（ms まで）、直前のブロックとの間隔（8 ms より大きければ出力が遅れたということ）、トリガーの経路、トリガー・左グリップ・右グリップの最大値（±112 が最大）、速度・ギア・アクセル・ブレーキ・路面、そのブロックのイベントです。1 時間で約 30 MB、直近 10 ファイルだけ残します。スイッチはすぐ保存され、次の **開始** から有効になります。記録が始まるとイベントログにファイル名が出ます。 |
| **記録フォルダー ↗** | デバッグ記録のフォルダーをエクスプローラーで開きます。 |
| **前回のセッション: 遅延フレーム / 最大 ms**（右側） | 直前のセッションで 8 ms の出力周期に間に合わなかった回数と、いちばん遅れた時間です。0 に近ければ正常です。 |

### 状態表示

出力制御の行の右に `コントローラーの状態 · テレメトリーの状態` の形で出ます。先頭の点は、緑なら出力中、黄色なら開始したがまだコントローラーを掴んでいない状態（ゲーム待機など）、赤ならエラー、灰色なら停止中です。

| メッセージ | 意味と対処 |
|---|---|
| `停止中` | 出力していない状態です。 |
| `コントローラー未使用 · ゲーム待機中（ATS/ETS2 未起動）` | 開始はしましたが、ゲームがまだ起動していません。コントローラーは掴んでいません。 |
| `APEX 6 Pro · 走行中（Local\…Telemetry）` | 正常に動作しています。括弧の中はデータを読んでいるプラグインの共有メモリ名です。 |
| `… · 一時停止/メニュー` | ゲームが一時停止中かメニュー画面です。振動を止めます。 |
| `… · テレメトリー停止中（最小化/読み込み中）` | ゲームデータが 0.3 秒以上更新されていません。読み込み中か、ウィンドウが最小化されている場合です。 |
| `… · テレメトリー待機中（ゲーム読み込み中、またはプラグインなし）` | ゲームは実行中ですがテレメトリーがありません。読み込みが終わっても続くならプラグインをインストールしてください。 |
| `テレメトリーなし: … プラグインのリビジョン N（対応: 12）…` | インストールされたプラグインのデータ構造のバージョンが合いません。プラグイン ウィンドウからインストールしてください。 |
| `コントローラーなし（有線/2.4Gドングルの接続と電源を確認） · 2 秒後に再試行` | コントローラーが見つかりません。接続を確認してください。2 秒ごとに自動で再試行します。 |
| `コントローラーが見えません: Steam から起動されたため Steam Input がパッドを隠しています …` | Steam が起動したプロセス（例: Steam 以外のゲームとして登録した ATSHaptics）では、ゲームの Steam Input がオンだとパッドが見えません。ウィンドウを直接起動するか、下の起動オプションを使ってください。 |
| `コントローラーが応答しません（スリープ中ならボタンを押して起こしてください）` | ドングルは見えていますが、コントローラーが応答しません。ボタンを押して起こせば自動で続きます。 |
| `コントローラーの接続が切れました（…）` | 走行中に接続が切れました。つながり直せば自動で続きます。 |
| `ゲーム終了、コントローラーを解放しました` | ゲームが終わったのでコントローラーを解放しました。次のゲーム起動を待ちます。 |
| `エラー: …` | 自動では回復しない問題です（例: APEX 6 Pro ではない機種）。詳しい内容は `%APPDATA%\ATSHaptics\logs\error.log` に残ります。 |

## テレメトリープラグイン ウィンドウ

![テレメトリープラグイン ウィンドウ](docs/screenshot-plugins.png)

振動は、ゲームにインストールされたテレメトリープラグイン（RenCloud scs-sdk-plugin 系、データ構造 rev 12）が出力するデータを読んで作ります。このウィンドウは Steam ライブラリから ATS/ETS2 のインストールフォルダーを探し、`bin\win_x64\plugins` にどのプラグインがあるかを表示します。

| 表示 | 意味 |
|---|---|
| `RenCloud`、`TruckDash` | 互換性があります。そのまま使えます。 |
| `SimHub` | SimHub 用のプラグインです。データ構造が確認できていないため「互換性未確認」と表示されます。 |
| `テレメトリープラグインなし` | **インストール** を押してください。 |

- **インストール / 再インストール:** 同梱の RenCloud `scs-telemetry.dll`（v1.12.1、MIT）をゲームの `plugins` フォルダーにコピーします。ほかのプラグインには触れません。ゲームが実行中なら、次回の起動から有効になります。
- **ゲームフォルダーを選ぶ…:** Steam 以外のインストールや見つからなかった場合に、ゲームフォルダー（`bin\win_x64\amtrucks.exe` または `eurotrucks2.exe` があるフォルダー）を指定します。
- ゲームフォルダーに書き込む権限がない場合は、エラー画面にコピーするファイルと場所が表示されます。管理者として実行するか、手動でコピーしてください。
- プラグインがあると、ゲーム起動時に「Advanced SDK features」の案内が出ることがあります。テレメトリープラグインが正常に読み込まれたという意味です。

## ゲームと一緒に起動 (Steam 起動オプション)

Steam ライブラリでゲームの **プロパティ → 一般 → 起動オプション** に次のように入力します。パスは展開した場所に変えてください。

```
"C:\Tools\ATSHaptics\ATSHaptics.exe" --launch %command%
```

- ゲームを起動するとウィンドウが**最小化された状態で一緒に開き、自動で開始**します。ゲームを終了するとウィンドウも閉じます。未保存の変更があれば、閉じる前に尋ねます。
- 常駐するプログラムはありません。ゲームの起動状態は、ウィンドウが開いている間だけ 2 秒ごとに確認します。
- 既存の起動オプション（例: `-nointro`、`-rdevice dx11`）は `%command%` の後ろに付けます。
- ウィンドウがすでに開いていれば 2 つ目のウィンドウは開かず、開いているウィンドウが停止中なら **ATS/ETS2 ゲーム** 入力で開始します（自動開始スイッチとは関係なく）。そのウィンドウはゲームが終わっても閉じません。
- ウィンドウは Steam が起動したプロセスの外側（WMI）から開きます。Steam はゲームとその子プロセスにオーバーレイを入れ、ゲームの Steam Input がオンだとそれらのプロセスからパッドを隠すためです。そのため Steam Input をオンにしたままでもパッドを掴めます。

## アップデート

ウィンドウを開くと GitHub で最新リリースを確認します。新しいバージョンがあれば右上に **アップデート x.y.z** ボタンが出ます。オフラインなら何も言わずにスキップします。

- ボタンを押すとリリースノートを表示し、確認すると zip をダウンロードして、GitHub が公開している SHA-256 と一致するか検査します。
- ダウンロード後にウィンドウが閉じ（未保存の変更があれば先に尋ねます）、プログラムが完全に終了したら新しいファイルをインストールフォルダーに上書きし、新しいバージョンを起動し直します。設定（`%APPDATA%\ATSHaptics`）はそのままです。
- 上書きの前にインストールフォルダーをバックアップし、コピーに失敗したら前のバージョンに戻してから起動します。2 分たってもプログラムが終了しなければ何も変更しません。
- ゲームの実行中はアップデートしません。Steam 起動オプションで開いた場合、ゲームが終わるまで実行ファイルが使用中だからです。ゲームを終了してからウィンドウを開き直してアップデートしてください。
- インストールフォルダーに書き込む権限がない場合（例: `Program Files`）や、ソースから実行している場合はリリースページを開くだけです。
- インストールの記録は `%TEMP%\ATSHaptics-update-<バージョン>\unpacked\apply-update.log` に残ります。

## 調整のコツ

1. **テスト走行** から始め、出力メーターを見ながら全体の強さを決めます。
2. 実際の走行でエフェクトを 1 つずつオン/オフして比べます。スイッチはすぐ反映されます。
3. 長距離でエンジンやトリガーの振動のせいで手が疲れるなら、強さを下げる前に **定速時に弱める** を 70〜90% に上げてみてください。定速区間は静かになり、加速やシフトのように操作する瞬間の感触はそのまま残ります。それでも気になるなら **エンジン** を 20〜30% に下げてください。
4. トリガーが指に負担なら **出力の強さ → トリガー** を下げてください。エフェクトごとの比率はそのままです。
5. 特定のエフェクトを指で感じたいなら（例: エンジンの振動をアクセルのトリガーで）、そのエフェクトの振動の場所を **トリガー** か **両方** に変えてください。
6. 舗装路で段差パルスが多すぎるなら **段差しきい値** を上げてください。
7. 走行中にウインカーやシフトのようなイベントが感じにくいなら、**イベント優先** を上げるか **エンジン**・**路面** を下げてください。イベントのたびに走行振動が揺れる感じが嫌なら、イベント優先を下げてください。
8. （ソースから実行する場合）エンジンがアイドリングでは弱く巡航でだけ強く感じる、ウインカーのような高い「カチ」が弱い、というときは `tone.py calibrate` でモーターの周波数ごとの体感の強さをそろえてください。モーターはグリップ約 65 Hz、トリガー約 100 Hz でいちばん強く鳴るので、同じ強さで送っても周波数ごとに感じ方が違います。基準音と同じに感じるまで試験音を上げ下げすると、その倍率が周波数ごとにすべてのエフェクトにかかります（`config.json` の `eq`、次の開始から）。測る前は補正なしで、`tone.py calibrate --reset` で消せます。
9. 気に入ったら **保存** を押してください。

## トラブルシューティング

**まったく振動しません。**
- 状態表示が `APEX 6 Pro · 走行中` になっているか確認してください。別のメッセージなら[状態表示の表](#状態表示)を見てください。
- xHaptics Engine が起動していれば終了してください。
- 出力メーターは動くのに振動がないなら、出力の強さとコントローラーの接続方式（Bluetooth 非対応）を確認してください。

**ゲームを起動すると振動しないのに、プログラムを再起動すると直ります。** 0.1.0 のバグです。ゲームや Steam が読み込み中にゲームパッドを初期化したり、コントローラーがスリープ後にドングルとつながり直したりすると、コントローラーのファームウェアがモーター設定を失います。このときもデータ送信はエラーなく続くため、再試行が起きませんでした。現在は出力中にモーター設定を定期的に送り直すので（静かなときは 1 秒、振動中は 4 秒間隔）、数秒以内に自然に回復します。

**テレメトリーの値が `-` のままです。**
- ゲームが一時停止/メニューの状態か確認してください。
- プラグイン ウィンドウで互換プラグイン（RenCloud、TruckDash）があるか確認し、なければインストールしてからゲームを起動し直してください。

**トリガーが両方とも振動します。** コントローラーの制限です。[既知の制限](#既知の制限)を見てください。

**Steam でゲームを起動してもウィンドウが開きません。**
- 起動オプションのパスと引用符を確認してください。
- すでにウィンドウが開いていると、新しいウィンドウは開きません（タスクバーを確認してください）。

**文字が違う言語で表示されます。** 右上の言語メニューで選んでください。選んだ言語は `config.json` の `app.language` に保存され、この値を消すと再び Windows の表示言語に従います。

**設定を初期化したいです。** **既定値** → **保存** を押すか、`%APPDATA%\ATSHaptics\config.json` を削除してください。

**ときどき振動がおかしく跳ねます。** 下の **デバッグ記録** をオンにしてもう一度 **開始** し、跳ねたときに時計を見て時刻を覚えておいてください。その時刻付近の行で `gap_ms` が 8 より大きく跳ねていれば出力が遅れたということで、`trigger`/`left_grip`/`right_grip` の値が急に大きくなっていれば、このプログラムがそう送ったということです。どちらも普段どおりなら、プログラムの外の原因（無線の干渉、ゲームや Steam Input の振動、ファームウェア）です。問い合わせのときはこのファイルと時刻を一緒に送ってください。

**問い合わせ用に情報を集めたいです。** `ATSHaptics.exe --selftest` を実行すると、`%TEMP%\ATSHaptics-selftest.txt` にバージョン、コントローラーの認識、ゲーム・プラグインの検出結果が記録されます。状態表示に `エラー: …` が出たなら、`%APPDATA%\ATSHaptics\logs\error.log` も一緒に送ってください。予期しないエラーが時刻とともに記録されています。

## 既知の制限

- トリガーチャンネルは 1 つだけなので、左右の区別なく**両方のトリガーを一緒に**振動させます。グリップは左右独立です。コントローラーのファームウェア 9.0.5.5 で `tone.py split`（基準音と比べるブラインドチェック）を使って確認しました。経路を左や右に指定しても、ブロックごとに交互に送っても、両方のトリガーで同じように感じられました。Flydigi Space Station と X-Haptics もトリガーを左右の区別のない 1 つの部位として扱っています。
- テレメトリーにはエンジンの気筒数やワイパーの速度といった情報がないため、該当するエフェクトは手動設定か対象外です。
- 非公式のリバースエンジニアリングに基づいているため、コントローラーのファームウェア更新で動作が変わることがあります。

## ソースから実行とビルド

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\pythonw.exe app.py                    # ウィンドウ（または start_gui.cmd）
.\.venv\Scripts\python.exe ats_haptics.py --monitor   # コマンドライン: --simulate, --exit-with-game, エフェクトごとの強さ
.\.venv\Scripts\python.exe tone.py probe              # 診断: probe | tone | sweep | walk | route-test | diag | split | calibrate
.\.venv\Scripts\python.exe tone.py split              # トリガー左右分離のブラインドチェック、結果は logs\trigger-split-*.txt
.\.venv\Scripts\python.exe tone.py calibrate          # 周波数ごとの体感の強さをそろえる（補正）、--reset で消去
powershell -ExecutionPolicy Bypass -File build.ps1    # dist\ATSHaptics-<バージョン>.zip（ソース同梱）
.\.venv\Scripts\python.exe i18n.py                  # 翻訳チェック: 抜け、未使用、{プレースホルダー} の不一致
.\.venv\Scripts\python.exe -m unittest              # 回帰テスト（tests\）
```

画面の文言は、コード内の韓国語の原文がそのままキーになっています（`t("정지됨")`）。翻訳は `locales\<言語>.py` の `MESSAGES` にあり、翻訳がなければ英語、その次に韓国語で表示されます。文言を変えたり追加したりしたら、`i18n.py` を実行してすべての言語の表に反映されているか確認してください。

ソースからの Steam 起動オプション: `"<repo>\.venv\Scripts\pythonw.exe" "<repo>\launch.py" %command%`

構成:

```
ATS ─(scs-telemetry 共有メモリ)─▶ telemetry.py ─▶ effects.py (1 kHz 合成) ─▶ apex6.py ─(HID 0x57, 8 ms)─▶ APEX 6 Pro
                                    gamewatch.py: ゲーム起動の検出     plugin_install.py: プラグインの検出・インストール
                                    updater.py: GitHub リリースの確認と自動アップデート
                                    i18n.py + locales\: 画面の言語     gui.py + widgets.py: ウィンドウ、ツールチップ
                                    blocklog.py: デバッグ記録          errorlog.py: 予期しないエラーの記録
```
