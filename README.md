# ATS 햅틱 for Flydigi APEX 6 Pro

**한국어** · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh.md)

American Truck Simulator / Euro Truck Simulator 2의 텔레메트리로 Flydigi APEX 6 Pro의 VCM(보이스 코일) 모터를 직접 구동합니다. 게임 소리를 분석하는 X-Haptics와 달리 엔진 rpm, 노면, 서스펜션, 페달 같은 게임 데이터로 진동을 만들고, 창에서 실시간으로 조절합니다.

## 요구 사항

- Windows 10/11
- Flydigi **APEX 6 Pro** (유선 또는 2.4 GHz 동글. 블루투스와 일반 APEX 6은 지원하지 않습니다)
- American Truck Simulator 또는 Euro Truck Simulator 2
- 실행 중에는 **xHaptics Engine을 꺼 두세요.** 같은 모터로 출력해서 진동이 섞입니다. Space Station 웹 페이지는 탭만 닫아 두면 됩니다.

## 설치와 빠른 시작

1. [Releases](../../releases)에서 `ATSHaptics-<버전>.zip`을 받아 원하는 곳에 압축을 풉니다.
2. `ATSHaptics\ATSHaptics.exe`를 실행합니다. 설치 과정은 없습니다.
3. 게임에 쓸 수 있는 텔레메트리 플러그인이 없으면 [플러그인 창](#텔레메트리-플러그인-창)이 자동으로 열립니다. **설치**를 누르세요.
4. 먼저 **테스트 주행** → **시작**으로 진동이 오는지 확인합니다(게임 없이 60초 시나리오).
5. **ATS/ETS2 게임** → **시작**을 누르고 게임을 실행합니다. 게임이 켜지면 컨트롤러를 잡고, 게임이 끝나면 놓습니다.

게임을 켤 때마다 자동으로 뜨게 하려면 [Steam 실행 옵션](#게임과-함께-실행-steam-실행-옵션)을 설정하세요.

## 화면 설명

모든 슬라이더, 스위치, 버튼, 표시값에 마우스를 잠시 올려 두면 무엇을 하는지 설명하는 툴팁이 나옵니다. 아래 표의 내용을 줄여 담은 것입니다.

### 위쪽 바와 출력 제어

| 항목 | 설명 |
|---|---|
| **입력: ATS/ETS2 게임** | 게임 텔레메트리로 진동을 만듭니다. ATS(`amtrucks.exe`)나 ETS2(`eurotrucks2.exe`)가 실행 중일 때만 컨트롤러를 사용합니다. |
| **입력: 테스트 주행** | 게임 없이 정해진 60초 배송 코스를 재생하고 반복합니다. 시동 → 트레일러 연결 → 출발 휠스핀 → 가속·변속(스플리터, 레인지) → 고속도로(왼쪽 깜빡이, 왼쪽 포트홀, 오른쪽 차선 요철) → 콘크리트 이음매 → 자갈길(오른쪽 깜빡이) → 나무 다리 → 눈길 → 빙판 휠스핀 → 내리막 리타더와 엔진 브레이크 → 급제동(휠락, 브레이크 스퀼) → 톨게이트 → 비상등 켜고 후진해 도크에 쿵(충돌) → 파킹 브레이크 → 트레일러 분리 → 배송 완료 → 시동 끔 순서입니다. 트레일러 바퀴는 트럭이 지난 요철을 0.45초 뒤에 따라 밟습니다. 효과를 확인하거나 튜닝할 때 씁니다. |
| **▶ 시작 / ■ 정지** | 하나의 버튼입니다. 초록 **시작**을 누르면 진동을 내보내고 버튼이 빨간 **정지**로 바뀝니다. 정지하면 모터를 끄고 컨트롤러를 놓습니다. 실행 중에는 입력(게임/테스트 주행)을 바꿀 수 없습니다. |
| **게임 감지 시 자동 시작** (스위치) | 켜 두면 창이 정지 상태일 때 게임이 실행되는 순간 자동으로 시작합니다. 게임 도중 직접 정지했다면 그 게임이 끝날 때까지는 다시 켜지지 않습니다. 스위치를 바꾸면 바로 저장됩니다. |
| **GitHub ↗** | 이 프로그램의 GitHub 저장소(소스, 릴리스, 문의)를 브라우저로 엽니다. |
| **언어 메뉴** (예: `한국어 ▾`) | 화면 언어를 고릅니다: 한국어, English, 日本語, 简体中文, Deutsch, Français, Español, Português (Brasil), Polski, Русский. 바로 다시 그려지고 튜닝 값과 실행 상태는 그대로이며, 고른 언어는 바로 저장됩니다. 고르기 전에는 Windows 표시 언어를 따르고, 목록에 없는 언어면 영어로 나옵니다. 상태 메시지와 이벤트 로그도 같은 언어로 나옵니다. 이미 기록된 이벤트 줄은 그대로 남습니다. |
| **텔레메트리 플러그인** | [플러그인 창](#텔레메트리-플러그인-창)을 엽니다. |
| **업데이트 x.y.z** | GitHub에 더 새 릴리스가 있을 때만 나타납니다. [업데이트](#업데이트)를 보세요. |

### 출력 세기와 출력 미터

컨트롤러로 나가는 **최종 세기**입니다. 아래 효과별 세기를 모두 섞은 다음에 적용됩니다. 범위는 0~150%, 기본값은 100%입니다.

| 항목 | 설명 |
|---|---|
| **전체** | 그립과 트리거 모두에 적용됩니다. |
| **그립** | 좌우 그립 모터에만 적용됩니다. |
| **트리거** | 트리거 모터에만 적용됩니다. 0%로 두면 트리거 진동이 완전히 꺼집니다. |

출력이 커지면 여러 효과가 겹칠 때 부드럽게 포화되도록 제한(소프트 리미터)이 걸립니다. 100%를 넘기면 약한 효과는 세지고, 이미 센 효과는 거의 그대로입니다.

**모터 보정…** (미터 아래)은 모터가 주파수마다 다르게 울리는 정도를 손으로 맞춥니다. 모터는 그립 약 65Hz, 트리거 약 100Hz에서 가장 세게 울려서 같은 세기로 보내도 주파수마다 다르게 느껴지는데(공회전 엔진은 약하고 크루즈 rpm에서만 세게 느껴지는 식), 이걸 주파수별로 바로잡습니다. 이웃한 두 주파수(예: 80Hz와 65Hz)가 무작위 순서로 차례로 울리면 어느 쪽이 더 셌는지 고르면 됩니다. 조금이라도 센 쪽이 있으면 그쪽을, 정말 구분이 안 되면 아무 쪽이나 고르세요. 구분이 안 된다는 건 거의 같아졌다는 뜻이라 결과가 틀어지지 않습니다. 답에 따라 처음엔 3dB, 판단이 한 번 뒤집힌 뒤로는 1.5dB씩 좁혀 가며 같게 느껴지는 세기를 찾고, 기준(그립 65Hz, 트리거 100Hz)에서 바깥쪽으로 이웃을 따라 이어 갑니다. 그립은 30~250Hz 9개, 트리거는 50~250Hz 7개 주파수이고 모터 하나에 3~5분 걸립니다. 패드 버튼으로 답할 수 있습니다: 십자키 ← 또는 LB 첫 번째, → 또는 RB 두 번째, X 다시 듣기, B 그만(키보드는 ← → 또는 1 2, R, Esc). 재생 중에 눌러도 바로 반영됩니다. 창의 버튼마다 아래에 같은 답을 내는 패드·키보드 버튼이 적혀 있습니다. 모터 하나를 끝까지 맞추면 `config.json`의 `eq`에 저장되고, 다음 시작부터 모든 효과에 주파수별로 적용됩니다(×0.25~×4). 그립 커브는 대부분의 주파수를 3~4배 올리게 되므로 커브 전체를 0.4배로 낮춰 적용합니다. 주파수 사이의 균형만 바뀌고 전체 세기는 보정 전과 비슷해서, 센 진동이 출력 한계에 눌리지 않습니다. 곡선에 나타난 공진(가장 적게 보내도 되는 주파수)은 짧은 진동 뒤에도 수십 ms 동안 울려서 '톡'을 둥근 웅웅거림으로 뭉개기 때문에, 출력마다 그 공진을 곡선만큼 깎는 필터를 거치고 효과마다 자기 주파수에서 그만큼 메워 줍니다. 계속 울리는 진동의 세기는 그대로이고, 짧은 진동은 만든 모양대로 또렷하게 끊깁니다. 측정하기 전에는 개발자의 APEX에서 손으로 맞춘 기본값을 쓰고, **보정 지우기**를 누르면 기본값으로 돌아갑니다. 그립과 트리거 중 직접 잰 쪽만 바뀝니다. 출력을 정지한 상태에서만 열 수 있고, 보정하는 동안에는 시작 버튼과 게임 감지 자동 시작이 기다립니다.

**미터**는 왼쪽 그립 / 오른쪽 그립 / 트리거로 실제로 나가는 세기를 보여 줍니다. 진동이 약하거나 없을 때 어느 단계에서 줄어드는지 확인하는 용도입니다.

### 주행 효과

왼쪽 스위치로 효과별로 켜고 끌 수 있습니다. 끄면 그 줄이 흐려지지만 슬라이더 값과 진동 위치는 남아서, 다시 켜면 그대로 돌아옵니다.

오른쪽 **진동 위치**에서 **그립**(파랑) | **트리거**(주황) | **둘 다**(보라) 중 하나를 눌러 효과마다 진동이 갈 곳을 고릅니다(주행 효과와 이벤트 효과 모두). 슬라이더 색도 고른 위치의 색을 따라가서 어떤 효과가 어디로 가는지 한눈에 보입니다. 꺼진 효과에서 위치를 누르면 그 위치로 다시 켜집니다. 표의 "기본 출력"은 처음 설정입니다. 좌우가 있는 효과(노면, 요철, 방향지시등)를 트리거로 보내면 좌우를 합쳐 트리거에 냅니다. 트리거 효과를 그립으로 보내면 양쪽 그립에 같이 냅니다. 바로 반영되고, **저장**하면 유지됩니다.

각 줄 맨 오른쪽 **▶**를 누르면 그 효과만 몇 초 동안 울립니다. 지금 세기, 진동 위치, 모터 보정 그대로이고 꺼 둔 효과도 울립니다. 요철, 차선 요철, 방향지시등은 왼쪽 다음 오른쪽 순서라 좌우가 제대로 갈리는지 확인할 수 있고, 출력 미터에도 나옵니다. 출력을 정지한 상태에서는 그동안만 컨트롤러를 잡고, 출력 중에는 그 몇 초 동안 주행 진동 대신 울립니다.

| 효과 | 기본값 (범위) | 기본 출력 | 내용 |
|---|---|---|---|
| **엔진** | 10% (0~200) | 양쪽 그립 | 엔진 점화 주파수(rpm ÷ 60 × 기통 수 ÷ 2, 6기통이면 rpm ÷ 20)에 2배음을 더한 진동입니다. 엑셀을 밟을수록, rpm이 높을수록 세집니다. 폭발마다 세기가 다르고(±18%), 실린더마다 폭발이 고르지 않습니다. 공회전에서 가장 고르지 않아 울렁이고, rpm과 부하가 오르면 줄지만 실제 엔진 녹음처럼 다 사라지지는 않습니다. 부하가 크면 3배음이 더해져 거칠어집니다. 시동이 꺼져 있으면 없습니다. |
| **노면** | 50% (0~200) | 그립 좌/우 따로 | 바퀴 아래 노면 재질과 속도로 세기와 질감이 정해지고, 서스펜션의 잔떨림도 더해집니다. 세기는 얼음 < 아스팔트 < 콘크리트 < 눈 < 나무 < 금속 < 잔디 < 흙 < 자갈 순입니다. 실제 타이어 소리의 저음 성분을 참고해서 재질마다 떨림의 높이가 다르고(얼음 140Hz, 잔디·금속 130Hz, 아스팔트 100Hz, 자갈 85Hz, 눈 70Hz, 나무 65Hz), 느릴수록 낮아집니다(정지 시 60%). 자갈·흙·눈·거친 포장에는 돌이 튀는 '탁탁'이 섞이는데, 대부분 작고 가끔 큰 돌이 세게 칩니다(자갈은 1m에 약 3개). 녹음된 노면 소리처럼 1초에 몇 번씩 출렁이고(약 4Hz), 서스펜션이 거칠게 움직이는 험한 길에서는 캡이 덜컹거리는 55Hz 충격이 초당 최대 40번 섞입니다. 포장 상태(매끈한 포장 `road_smooth` < 일반 도로 < 거친 포장 `road_coarse` < 흙 덮인 도로 `road_dirt`)도 구분합니다. |
| **요철** | 100% (0~200) | 해당 바퀴 쪽 그립 | 서스펜션이 갑자기 움직이면(포트홀, 연석, 이음매) 충격을 냅니다. 실제 요철 소리를 참고해서 작은 이음매는 짧고 높은 '톡'(65Hz, 0.025초), 큰 포트홀은 낮고 묵직한 '쿵'(40Hz, 0.06초)으로 크기에 따라 달라지고, 큰 충격 뒤에는 캡이 0.3초쯤 작게 덜컹거립니다. 왼쪽 바퀴는 왼쪽 그립, 오른쪽 바퀴는 오른쪽 그립으로 갑니다. 트레일러 바퀴의 요철은 절반 세기에 조금 더 높게(+10Hz) 뒤따라 옵니다. |
| **차선 요철** | 80% (0~200) | 해당 바퀴 쪽 그립 | 중앙선이나 갓길의 럼블 스트립을 밟으면 '드르르륵' 진동을 냅니다. 게임이 바퀴마다 알려 주는 노면 재질(`rumble_stripe`)로 감지하므로 서스펜션이 거의 움직이지 않아도 울립니다. 홈 간격(약 30cm)과 속도로 주파수가 정해져서, 시속 90km면 약 83Hz입니다. 실제 차선 요철 녹음처럼 거의 순음에 가깝고, 홈 하나 건너 하나가 더 세게 옵니다. 트레일러 바퀴만 걸쳐도 절반 세기로 울립니다. |
| **휠스핀** | 70% (0~200) | 양쪽 그립 | 엑셀을 밟는데 구동 바퀴가 트럭보다 확실히 빨리 돌면(얼음, 눈, 진흙, 급출발) 거칠게 긁히는 45Hz 진동을 냅니다. 타이어가 붙었다 미끄러졌다 하듯 13Hz로 떨립니다. 브레이크로 바퀴가 잠기는 휠락은 **엑셀/브레이크**에서 냅니다. |
| **변속** | 80% (0~200) | 양쪽 그립 | 기어가 바뀔 때 '철컥'. Zeemods 사운드 팩에 있는 실제 이튼 풀러 변속음 녹음을 본떴습니다. 레버가 기어에서 빠지는 약한 '툭'(주행 진동이 여기서부터 줄어듭니다)이 지나고, 변속 0.14초 뒤 140Hz의 또렷한 '철컥'으로 다음 기어가 들어가며 기어박스 울림이 짧게 남습니다. 녹음과 같은 타이밍이라 그 팩의 변속음과 함께 울립니다. 자동 변속기도 동작합니다. |
| **리타더** | 30% (0~200) | 양쪽 그립 | 리타더 단계에 비례하는 웅웅거림입니다. 빠를수록 음이 높아지고(정지 40Hz → 시속 90km 이상 65Hz), 저속에서는 줄어듭니다. 엔진 브레이크는 엔진 점화 박자(6기통이면 rpm ÷ 20)에 맞춰 '다다닥' 노크하는 진동이고, rpm이 높을수록 세며 엑셀을 밟으면 멈춥니다. |
| **충돌** | 100% (0~200) | 양쪽 그립 | 가속도가 순간적으로 크게 튀면(충돌, 큰 충격) 강한 50Hz 펄스를 냅니다. 기준은 [감지 기준](#감지-기준)에서 정합니다. |
| **엑셀/브레이크** | 30% (0~100) | 트리거 | 지금 밟고 있는 페달을 따라갑니다. 엑셀이면 밟은 만큼 세지는 100Hz, 브레이크면 바퀴가 잠길 때(휠락) 12Hz로 끊기는 110Hz 펄스이고, 잠기지 않으면 속도와 제동량에 비례하는 약한 진동입니다. |
| **└ 엔진 박자** | 0% (0~100) | 엑셀/브레이크를 따름 | 엑셀 트리거 진동을 엔진 점화 박자에 맞춰 출렁이게 하는 정도입니다. 0%면 일정하게 울려 트리거에 엔진 느낌이 전혀 없고, 올릴수록 박자가 뚜렷해집니다(이전 버전은 80%로 고정). 박자는 그립의 엔진 진동과 같은 폭발을 따라가서, 공회전에서 실린더마다 고르지 않은 울렁임과 폭발마다 조금씩 다른 세기도 트리거로 느껴집니다. 브레이크 쪽에는 영향이 없습니다. |
| **정속 시 줄임** | 60% (0~100) | - | 장거리 정속 주행에서 손이 덜 피로하도록, rpm·엑셀 부하·페달이 그대로 유지되면 **엔진**과 **엑셀/브레이크** 진동이 몇 초에 걸쳐 이 비율만큼 서서히 줄어듭니다(약 5초에 절반, 10초면 거의 다). 가속, 변속, 엑셀을 떼거나 다시 밟는 순간에는 바로 원래 세기로 돌아옵니다. 60%면 정속에서 약 −7 dB, 80%면 약 −12 dB입니다. 0%면 줄이지 않습니다. 휠락 펄스는 경고라서 줄이지 않습니다. |

### 이벤트 효과

| 효과 | 기본값 | 기본 출력 | 내용 |
|---|---|---|---|
| **페달 바닥** | 60% | 트리거 | 엑셀이나 브레이크 입력이 끝까지(97% 이상) 닿는 순간 짧은 '툭' |
| **브레이크 스퀼** | 40% | 트리거 | 약 14km/h 이하에서 브레이크를 밟으며 서서히 멈출 때 '끼익, 끽' 하고 우는 230Hz. 실제 녹음처럼 0.15~0.5초씩 끊어져 울리고, 울 때마다 음높이가 조금씩 다릅니다 |
| **트레일러 연결** | 90% | 양쪽 그립 | 실제 커플링 녹음처럼 연결할 때 커플러가 0.6초쯤 '덜커덕덜컥' 맞물리고(20~40ms마다 한 번씩, 가장 센 한 방은 매번 다른 때), 분리할 때 '쿵'에 이어 에어 빠지는 느낌 |
| **파킹 브레이크** | 70% | 양쪽 그립 | 체결하면 '철컥'에 이어 스프링 브레이크의 에어가 빠지는 '쉬이익'(0.15초에 걸쳐 커졌다가 1초 가까이 걸쳐 잦아듦), 해제하면 낮은 '턱'에 이어 0.3초 뒤 짧은 '푸쉭' |
| **에어 브레이크** | 50% | 양쪽 그립 | 브레이크 페달을 0.3초 넘게 밟았다가 떼면 브레이크 챔버의 공기가 빠지며 50Hz '툭'에 이어 짧은 '푸쉬익'(0.04초에 걸쳐 커졌다가 약 0.35초에 걸쳐 잦아듦). 세게 밟았을수록 큽니다. 브레이크를 뗄 때마다 나므로 주행 진동을 줄이지 않습니다 |
| **방향지시등** | 70% | 켜진 쪽 그립 | 점멸할 때마다 릴레이처럼 짧고 높은 '틱'(190Hz, 몇 ms) |
| **시동 켜기/끄기** | 80% | 양쪽 그립 | 엔진 두 개의 시동·끄기 녹음을 따릅니다. 켤 때 스타터가 물리며 '툭', 1초쯤 압축 노크가 '퉁 퉁' 이어지다가 엔진이 걸리며 폭발이 빨라지고 '부웅'(걸리고 0.2~0.3초 뒤가 가장 셈). 끌 때는 0.3초쯤 공회전 박자로 더 돌다가 뚝 약해지며 1초 안에 '투둑투둑' 잦아듭니다. 게임이 크랭킹을 시작할 때 시동 켜짐을 알린다고 가정합니다. |
| **레인지/스플리터** | 70% | 양쪽 그립 | H-시프터의 레인지 셀렉터나 스플리터 스위치를 조작할 때 '딸깍'(레인지는 140Hz, 스플리터는 낮은 60Hz)에 이어, Zeemods 녹음처럼 0.13~0.17초 뒤 변속기가 공기로 넘어가며 '철컥'(170Hz). 레인지는 기어 변속만큼 세고, 스플리터는 12dB 약합니다. 자동/순차 변속에서는 울리지 않습니다. |
| **게임 알림** | 50% | 양쪽 그립 | 톨게이트, 벌금, 주유, 배송 완료, 페리, 기차 이벤트 때 '톡톡' 두 번 |
| **└ 주행 진동 양보** | 70% (0~100) | - | 이벤트 효과(변속, 충돌 포함)가 울리는 순간 같은 위치의 주행 진동(엔진, 노면, 차선 요철, 휠스핀, 리타더, 엑셀/브레이크)을 잠깐 줄여서 이벤트가 묻히지 않게 하는 정도입니다. 70%면 이벤트가 가장 셀 때 주행 진동이 30%까지 내려갔다가 약 0.1초 안에 돌아옵니다. 0%면 줄이지 않습니다. 요철은 노면에서 계속 나는 효과라 주행 진동을 줄이지 않습니다. |

이벤트 효과 범위는 모두 0~200%입니다.

### 감지 기준

| 항목 | 기본값 (범위) | 설명 |
|---|---|---|
| **요철 감지 기준** | 20 cm/s (5~100) | 서스펜션이 이 속도보다 갑자기 빨리 움직이면 요철 펄스를 냅니다. 낮추면 작은 요철에도, 높이면 큰 충격에만 반응합니다. |
| **충돌 감지 기준** | 12 m/s² (4~40) | 게임 화면 한 프레임 사이의 가속도 변화가 이 값을 넘으면 충돌 펄스를 냅니다. 평소 주행 중 [텔레메트리](#텔레메트리)의 "가속도 최대" 값보다 충분히 높게 두세요. |
| **엔진 기통 수** | 6 (4~12) | 엔진 진동 주파수 계산에 씁니다. ATS 순정 트럭은 대부분 직렬 6기통이고, ETS2의 Scania V8 같은 트럭은 8로 두면 됩니다. 텔레메트리에는 기통 수 정보가 없어서 직접 지정합니다. |

### 텔레메트리

게임에서 지금 받고 있는 값입니다. 진동이 이상할 때 데이터가 제대로 들어오는지 확인하는 용도입니다.

| 항목 | 설명 |
|---|---|
| **속도 / RPM / 기어** | 게임 값 그대로입니다. 후진 기어는 음수, 중립은 0입니다. |
| **페달** | 엑셀/브레이크 입력(0~1)입니다. 크루즈 컨트롤처럼 게임이 대신 밟는 값은 포함하지 않습니다. |
| **노면** | 첫 번째 바퀴 아래 노면 재질의 게임 내부 이름입니다(예: `road`, `gravel`, `grass`). |
| **트리거** | 트리거 채널이 지금 따라가는 페달입니다(엑셀/브레이크/-). |
| **가속도 최대** | 최근 0.1초 동안 수평 가속도 최대값입니다. 충돌 감지 기준을 정할 때 참고합니다. |

### 이벤트 로그

변속, 충돌, 페달 바닥, 트레일러, 파킹 브레이크, 방향지시등, 시동, 게임 알림이 시간과 함께 기록됩니다. 컨트롤러 연결 문제도 여기에 남습니다. 최근 50개까지 보입니다.

### 저장 · 기본값 · 디버그 기록 · 지연 표시

| 항목 | 설명 |
|---|---|
| **저장** | 슬라이더, 켜기/끄기 상태, 진동 위치(그립/트리거/둘 다)를 `%APPDATA%\ATSHaptics\config.json`에 저장합니다. 저장하지 않으면 **저장** 버튼이 파랗게 바뀌고 "변경됨 · 저장 안 됨"이 표시되며, 창을 닫을 때 저장할지 묻습니다. |
| **기본값** | 모든 세기와 기준, 진동 위치를 기본값으로 되돌리고 모든 효과를 켭니다. 저장은 따로 눌러야 합니다. |
| **디버그 기록** (스위치) | 켜 두면 컨트롤러를 잡을 때마다(시작, 게임 실행, 연결이 끊겼다 다시 이어질 때) 컨트롤러로 보낸 8ms 블록을 한 줄씩 `%APPDATA%\ATSHaptics\logs\blocks-<날짜>-<시각>.csv`에 남깁니다. 열은 시각(ms까지), 직전 블록과의 간격(8ms보다 크면 출력이 늦은 것), 트리거 경로, 트리거·왼쪽 그립·오른쪽 그립 최대값(±112가 최대), 속도·기어·엑셀·브레이크·노면, 그 블록의 이벤트입니다. 1시간에 약 30MB이고 최근 10개 파일만 남깁니다. 스위치는 바로 저장되고 다음 **시작**부터 적용됩니다. 기록이 시작되면 이벤트 로그에 파일 이름이 나옵니다. |
| **기록 폴더 ↗** | 디버그 기록 폴더를 탐색기로 엽니다. |
| **지난 세션: 지연 프레임 / 최대 ms** (오른쪽) | 직전 세션에서 8ms 출력 주기를 놓친 횟수와 가장 늦었던 시간입니다. 0에 가까우면 정상입니다. |

### 상태 표시

출력 제어 줄 오른쪽에 `컨트롤러 상태 · 텔레메트리 상태` 형식으로 나옵니다. 앞의 점은 초록이면 출력 중, 노랑이면 시작했지만 아직 컨트롤러를 잡지 않은 상태(게임 대기 등), 빨강이면 오류, 회색이면 정지입니다.

| 메시지 | 뜻과 할 일 |
|---|---|
| `정지됨` | 출력하지 않는 상태입니다. |
| `컨트롤러 미사용 · 게임 대기 중 (ATS/ETS2 실행 전)` | 시작은 했지만 게임이 아직 실행되지 않았습니다. 컨트롤러를 잡지 않은 상태입니다. |
| `APEX 6 Pro · 주행 중 (Local\…Telemetry)` | 정상 동작 중입니다. 괄호 안은 데이터를 읽고 있는 플러그인의 공유 메모리 이름입니다. |
| `… · 일시정지/메뉴` | 게임이 일시정지했거나 메뉴 화면입니다. 진동을 멈춥니다. |
| `… · 텔레메트리 멈춤 (최소화/로딩)` | 게임 데이터가 0.3초 넘게 갱신되지 않았습니다. 로딩 중이거나 창이 최소화된 경우입니다. |
| `… · 텔레메트리 대기 중 (게임 로딩 중이거나 플러그인 없음)` | 게임은 실행 중인데 텔레메트리가 없습니다. 로딩이 끝나도 계속되면 플러그인을 설치하세요. |
| `텔레메트리 없음: … 플러그인 버전 N (지원: 12) …` | 설치된 플러그인의 데이터 구조 버전이 맞지 않습니다. 플러그인 창에서 설치하세요. |
| `컨트롤러 없음 (유선/2.4G 동글 연결, 전원 확인) · 2초 후 재시도` | 컨트롤러를 찾지 못했습니다. 연결을 확인하세요. 2초마다 자동으로 다시 시도합니다. |
| `컨트롤러 안 보임: Steam이 실행한 프로세스라 Steam Input이 패드를 숨김 …` | Steam이 실행한 프로세스(예: 비 Steam 게임으로 등록한 ATSHaptics)에서는 게임에 Steam Input이 켜져 있으면 패드가 보이지 않습니다. 창을 직접 실행하거나 아래 실행 옵션을 쓰세요. |
| `컨트롤러 응답 없음 (절전 중이면 버튼을 눌러 깨우세요)` | 동글은 보이지만 컨트롤러가 응답하지 않습니다. 버튼을 눌러 깨우면 자동으로 이어집니다. |
| `컨트롤러 연결 끊김 (…)` | 주행 중 연결이 끊겼습니다. 다시 연결되면 자동으로 이어집니다. |
| `게임 종료됨, 컨트롤러 해제` | 게임이 끝나서 컨트롤러를 놓았습니다. 다음 게임 실행을 기다립니다. |
| `오류: …` | 자동으로 복구되지 않는 문제입니다(예: APEX 6 Pro가 아닌 기종). 자세한 내용은 `%APPDATA%\ATSHaptics\logs\error.log`에 남습니다. |

## 텔레메트리 플러그인 창

![텔레메트리 플러그인 창](docs/screenshot-plugins.png)

진동은 게임에 설치된 텔레메트리 플러그인(RenCloud scs-sdk-plugin 계열, 데이터 구조 rev 12)이 내보내는 데이터를 읽어서 만듭니다. 이 창은 Steam 라이브러리에서 ATS/ETS2 설치 폴더를 찾아, `bin\win_x64\plugins`에 어떤 플러그인이 있는지 보여 줍니다.

| 표시 | 뜻 |
|---|---|
| `RenCloud`, `TruckDash` | 호환됩니다. 그대로 쓰면 됩니다. |
| `SimHub` | SimHub용 플러그인입니다. 데이터 구조가 확인되지 않아 "호환 미확인"으로 표시됩니다. |
| `텔레메트리 플러그인 없음` | **설치**를 눌러야 합니다. |

- **설치 / 재설치:** 동봉한 RenCloud `scs-telemetry.dll`(v1.12.1, MIT)을 게임의 `plugins` 폴더에 복사합니다. 다른 플러그인은 건드리지 않습니다. 게임이 실행 중이면 다음 실행부터 적용됩니다.
- **게임 폴더 직접 선택…:** Steam 외의 설치나 찾지 못한 경우 게임 폴더(`bin\win_x64\amtrucks.exe` 또는 `eurotrucks2.exe`가 있는 폴더)를 지정합니다.
- 게임 폴더에 쓸 권한이 없으면 오류 창에 복사할 파일과 위치가 나옵니다. 관리자 권한으로 실행하거나 직접 복사하세요.
- 플러그인이 있으면 게임 시작 때 "Advanced SDK features" 안내가 뜰 수 있습니다. 텔레메트리 플러그인이 정상적으로 로드됐다는 뜻입니다.

## 게임과 함께 실행 (Steam 실행 옵션)

Steam 라이브러리에서 게임 **속성 → 일반 → 실행 옵션**에 아래처럼 넣습니다. 경로는 압축을 푼 위치로 바꾸세요.

```
"C:\Tools\ATSHaptics\ATSHaptics.exe" --launch %command%
```

- 게임을 켜면 창이 **최소화 상태로 함께 뜨고 자동으로 시작**합니다. 게임을 끄면 창도 닫힙니다. 저장하지 않은 변경이 있으면 닫기 전에 묻습니다.
- 계속 떠 있는 상주 프로그램은 없습니다. 게임 실행 여부는 창이 열려 있는 동안에만 2초 간격으로 확인합니다.
- 기존 실행 옵션(예: `-nointro`, `-rdevice dx11`)은 `%command%` 뒤에 붙입니다.
- 창이 이미 열려 있으면 두 번째 창은 뜨지 않고, 열려 있는 창이 정지 상태라면 **ATS/ETS2 게임** 입력으로 시작합니다(자동 시작 스위치와 관계없이). 그 창은 게임이 끝나도 닫히지 않습니다.
- 창은 Steam이 실행한 프로세스 바깥(WMI)에서 띄웁니다. Steam은 게임과 그 자식 프로세스에 오버레이를 넣고, 게임에 Steam Input이 켜져 있으면 그 프로세스들에서 패드를 숨기기 때문입니다. 그래서 Steam Input을 켜 둔 채로도 패드를 잡습니다.

## 업데이트

창을 열 때 GitHub에서 최신 릴리스를 확인합니다. 더 새 버전이 있으면 오른쪽 위에 **업데이트 x.y.z** 버튼이 나타납니다. 오프라인이면 조용히 넘어갑니다.

- 버튼을 누르면 릴리스 노트를 보여 주고, 확인하면 zip을 내려받아 GitHub가 공개한 SHA-256 값과 맞는지 검사합니다.
- 받은 뒤 창이 닫히고(저장하지 않은 변경이 있으면 먼저 묻습니다), 프로그램이 완전히 끝나면 새 파일을 설치 폴더에 덮어쓰고 새 버전을 다시 실행합니다. 설정(`%APPDATA%\ATSHaptics`)은 그대로입니다.
- 덮어쓰기 전에 설치 폴더를 백업해 두고, 복사에 실패하면 이전 버전으로 되돌린 뒤 실행합니다. 2분이 지나도 프로그램이 끝나지 않으면 아무것도 바꾸지 않습니다.
- 게임 실행 중에는 업데이트하지 않습니다. Steam 실행 옵션으로 띄운 경우 게임이 끝날 때까지 실행 파일이 사용 중이기 때문입니다. 게임을 끈 뒤 창을 다시 열어 업데이트하세요.
- 설치 폴더에 쓸 권한이 없거나(예: `Program Files`) 소스에서 실행 중이면 릴리스 페이지만 열어 줍니다.
- 설치 과정 기록은 `%TEMP%\ATSHaptics-update-<버전>\unpacked\apply-update.log`에 남습니다.

## 튜닝 팁

1. **테스트 주행**으로 시작해서 출력 미터를 보며 전체 세기를 정합니다.
2. 실제 주행에서 효과를 하나씩 켜고 끄며 비교합니다. 스위치는 바로 반영됩니다.
3. 장거리에서 진동 때문에 손이 피로하면 **엔진**, **노면**, **엑셀/브레이크**처럼 계속 나는 효과를 낮추세요. **정속 시 줄임**은 rpm과 페달이 몇 초 동안 그대로일 때만 듣는데, 게임 속 도로는 실제보다 짧게 줄여 놓아 속도가 자주 바뀌므로 그런 구간이 생각보다 적습니다. 고속도로를 오래 달린다면 70~90%로 올려 보세요.
4. 트리거가 손가락에 부담스러우면 **출력 세기 → 트리거**를 낮추세요. 효과별 비율은 그대로 유지됩니다.
5. 특정 효과를 손가락으로 느끼고 싶으면(예: 엔진 진동을 엑셀 트리거로) 그 효과의 진동 위치를 **트리거**나 **둘 다**로 바꾸세요.
6. 포장도로에서 요철 펄스가 너무 잦으면 **요철 감지 기준**을 올리세요.
7. 주행 중에 방향지시등이나 변속 같은 이벤트가 잘 안 느껴지면 **주행 진동 양보**를 올리거나 **엔진**·**노면**을 낮추세요. 이벤트 때마다 주행 진동이 출렁이는 느낌이 싫으면 양보를 낮추세요.
8. 엔진이 공회전에서는 약하고 크루즈에서만 세게 느껴지거나, 방향지시등처럼 높은 '틱'이 약하면 **출력 세기 → 모터 보정…**으로 모터의 주파수별 체감 세기를 맞추세요.
9. 마음에 들면 **저장**을 누르세요.

## 문제 해결

**진동이 전혀 없어요.**
- 상태 표시가 `APEX 6 Pro · 주행 중`인지 확인하세요. 다른 메시지라면 [상태 표시 표](#상태-표시)를 보세요.
- xHaptics Engine이 켜져 있으면 끄세요.
- 출력 미터가 움직이는데 진동이 없다면 출력 세기와 컨트롤러 연결 방식(블루투스 미지원)을 확인하세요.

**게임을 켜면 진동이 안 오다가 프로그램을 다시 켜면 돼요.** 0.1.0의 버그입니다. 게임이나 Steam이 로딩 중에 게임패드를 초기화하거나 컨트롤러가 절전 후 동글에 다시 붙으면 컨트롤러 펌웨어가 진동 모터 설정을 잃습니다. 이때도 데이터 전송은 오류 없이 계속되어 재시도가 일어나지 않았습니다. 이제는 출력 중에 모터 설정을 주기적으로 다시 보내서(조용할 때 1초, 진동 중 4초 간격) 몇 초 안에 저절로 복구됩니다.

**텔레메트리 값이 `-`로만 나와요.**
- 게임이 일시정지/메뉴 상태인지 확인하세요.
- 플러그인 창에서 호환 플러그인(RenCloud, TruckDash)이 있는지 확인하고, 없으면 설치한 뒤 게임을 다시 실행하세요.

**트리거가 양쪽 다 울려요.** 컨트롤러의 제약입니다. [알려진 제약](#알려진-제약)을 보세요.

**Steam에서 게임을 켜면 창이 안 떠요.**
- 실행 옵션의 경로와 따옴표를 확인하세요.
- 이미 창이 열려 있으면 새 창은 뜨지 않습니다(작업 표시줄을 확인하세요).

**글자가 잘못된 언어로 나와요.** 오른쪽 위 언어 메뉴에서 고르세요. 고른 언어는 `config.json`의 `app.language`에 저장되고, 이 값을 지우면 다시 Windows 표시 언어를 따릅니다.

**설정을 초기화하고 싶어요.** **기본값** → **저장**을 누르거나, `%APPDATA%\ATSHaptics\config.json`을 지우세요.

**가끔 진동이 이상하게 튀어요.** 아래쪽 **디버그 기록**을 켜고 다시 **시작**한 뒤, 튈 때 시계를 보고 시각을 기억해 두세요. 그 시각 근처 줄에서 `gap_ms`가 8보다 크게 튀면 출력이 늦은 것이고, `trigger`/`left_grip`/`right_grip` 값이 갑자기 커지면 이 프로그램이 그렇게 보낸 것입니다. 둘 다 평소와 같다면 프로그램 밖의 원인(무선 간섭, 게임이나 Steam Input의 진동, 펌웨어)입니다. 문의할 때 이 파일과 시각을 함께 보내 주세요.

**문의할 때 정보를 모으고 싶어요.** `ATSHaptics.exe --selftest`를 실행하면 `%TEMP%\ATSHaptics-selftest.txt`에 버전, 컨트롤러 인식, 게임·플러그인 감지 결과가 기록됩니다. 상태 표시에 `오류: …`가 나왔다면 `%APPDATA%\ATSHaptics\logs\error.log`도 함께 보내 주세요. 예기치 못한 오류가 시각과 함께 기록됩니다.

## 알려진 제약

- 트리거 채널은 하나뿐이라 좌우 구분 없이 **양쪽 트리거를 함께** 울립니다. 그립은 좌우가 독립입니다. 컨트롤러 펌웨어 9.0.5.5에서 `tone.py split`(기준음과 비교하는 블라인드 점검)으로 확인했고, 라우트를 왼쪽이나 오른쪽으로 지정해도, 블록마다 번갈아 보내도 양쪽 트리거에서 똑같이 느껴졌습니다. Flydigi Space Station과 X-Haptics도 트리거를 좌우 구분 없는 한 부위로 다룹니다.
- 텔레메트리에는 엔진 기통 수, 와이퍼 속도 같은 정보가 없어서 해당 효과는 수동 설정이거나 제외되어 있습니다.
- 비공식 리버스 엔지니어링 기반이라 컨트롤러 펌웨어 업데이트로 동작이 바뀔 수 있습니다.

## 소스에서 실행 / 빌드

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\pythonw.exe app.py                    # 창 (또는 start_gui.cmd)
.\.venv\Scripts\python.exe ats_haptics.py --monitor   # 명령줄: --simulate, --exit-with-game, 효과별 세기 옵션
.\.venv\Scripts\python.exe tone.py probe              # 진단: probe | tone | sweep | walk | route-test | diag | split | calibrate
.\.venv\Scripts\python.exe tone.py split              # 트리거 좌우 분리 블라인드 점검, 결과는 logs\trigger-split-*.txt
.\.venv\Scripts\python.exe tone.py calibrate          # 창의 모터 보정과 같은 측정(콘솔), --reset으로 지움
powershell -ExecutionPolicy Bypass -File build.ps1    # dist\ATSHaptics-<버전>.zip (소스 포함)
.\.venv\Scripts\python.exe i18n.py                  # 번역 점검: 빠지거나 안 쓰이거나 {자리} 가 다른 문구
.\.venv\Scripts\python.exe -m unittest              # 회귀 테스트 (tests\)
```

화면 문구는 코드 안의 한국어 원문이 그대로 키입니다(`t("정지됨")`). 번역은 `locales\<언어>.py`의 `MESSAGES`에 있고, 빠진 번역은 영어, 그다음 한국어로 나옵니다. 문구를 바꾸거나 추가했으면 `i18n.py`를 실행해 모든 언어 표에 반영됐는지 확인하세요.

소스에서 Steam 실행 옵션: `"<repo>\.venv\Scripts\pythonw.exe" "<repo>\launch.py" %command%`

구조:

```
ATS ─(scs-telemetry 공유 메모리)─▶ telemetry.py ─▶ effects.py (1 kHz 합성) ─▶ apex6.py ─(HID 0x57, 8 ms)─▶ APEX 6 Pro
                                     gamewatch.py: 게임 실행 감지    plugin_install.py: 플러그인 감지·설치
                                     updater.py: GitHub 릴리스 확인·자동 업데이트
                                     i18n.py + locales\: 화면 언어    gui.py + widgets.py: 창, 툴팁
                                     blocklog.py: 디버그 기록          errorlog.py: 예기치 못한 오류 기록
                                     preview.py: 효과별 ▶ 테스트
```
